# Dokumen AI Monorepo Agent Notes

## Repository Shape

- Monorepo with `web`, `api`, `workers`, `packages`, `db`, `infra`, and `gpu`.
- `.codesight/wiki` is generated structural documentation. Use it for orientation, then read actual source files before editing.
- CI covers formatting, linting, commit message validation, docs generation, and app deployments.

## Version Control

- Commit messages must follow Conventional Commits.
- `CHANGELOG.md` and `.codesight/wiki` are generated by automation. Do not hand-edit generated docs unless explicitly requested.
- Do not read `CHANGELOG.md`; use git history or source files for implementation context.

## Database

- Database objects are defined by SQL scripts under `db/`.
- The database is pre-instantiation; update existing create/setup scripts directly rather than adding backward-compatibility migrations.
- Respect schema ownership and the app-specific database boundaries described in `AGENTS.md`.

## Agent Workflow

- Prefer the closest service-level `README.AGENTS.md` for local conventions.
- For architecture questions, use `.codesight/wiki/overview.md` and the relevant domain article before reading source.
- Keep changes scoped to the requested service or package.
