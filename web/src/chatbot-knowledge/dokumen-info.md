# Dokumen AI Knowledge Base

## Overview

Dokumen AI is an intelligent platform designed to turn unstructured PDFs into structured data. It acts as the connective tissue between unstructured documents and databases, enabling users to label entities, train models, and automate extraction workflows.

## Core Features

### 1. No-Code Interface

Users can visually annotate PDF regions with zero scripting required. By simply clicking and dragging on the document, users can establish dataset fields instantly.

### 2. Lightning Models

Dokumen AI provides fast, performant extraction models instantly. These models are tailored to support custom document schemas without the need for manual training code.

## Dashboard and Project Management

Within the platform, users can manage "Projects" which contain:

- **Documents:** PDFs uploaded by the user to be processed (up to 50 MB per file).
- **Entity Types:** Custom properties to extract (e.g., Vendor Name, Register ID, Date, Title, Agency, Summary, Contact Name).
- **Templates:** Rules applied for extraction.
- **Analytics Dashboard:** Visualizing total documents, total annotations, unique entity types found, and entity distribution charts.

## Demo

Users can try the engine before signing up. The Demo provides a visual labeling interface directly in the browser to experience how easy it is to draw bounding boxes and extract JSON entities.
